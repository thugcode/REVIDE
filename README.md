# Revide

인스타·유튜브에서 저장만 하고 잊는 숏폼을 **링크만 담으면 알아서 분류**하고, 같은 주제끼리 **노트로 묶어** 다시 꺼내 보는 보관함이에요.

- 공유 버튼 한 번으로 담기 (아이폰 단축어 · 안드로이드 설치)
- 게시물 미리보기(제목·캡션·해시태그)로 자동 분류, 애매한 것만 '분류함'에서 원탭 정리
- 고른 분류를 기억해서 쓸수록 정확해짐
- 옵시디언처럼 마크다운 노트, [[링크]], 백링크, 옵시디언 내보내기
- 구글 로그인으로 기기 간 동기화

배포 방법은 [GUIDE.md](GUIDE.md)를 보세요.
